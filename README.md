# HomeCrop IoT - Análisis y mejora del diseño de software

Actividad correspondiente a la materia de Ingeniería en Software.

## Proyecto

HomeCrop IoT es un sistema inteligente de monitoreo y riego para plantas en casa. El proyecto utiliza sensores, un microcontrolador ESP32, almacenamiento de datos y un sistema de riego automatizado para facilitar el cuidado de las plantas.

## Objetivo de la actividad

Analizar el diseño actual de HomeCrop IoT, identificar posibles problemas en la distribución de responsabilidades y proponer una estructura de software más organizada, comprensible y fácil de mantener.

## Contenido del repositorio

En este repositorio se documentará:

- El diseño original del sistema.
- Las responsabilidades identificadas.
- Los problemas de diseño encontrados.
- Las propuestas de mejora desarrolladas por cada integrante.
- Los diagramas comparativos.
- Las evidencias de participación individual mediante commits.
